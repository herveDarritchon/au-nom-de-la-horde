# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Commands

```bash
pnpm packs:build        # compile compendiums/YAML → packs/LevelDB
pnpm packs:extract      # extract packs/LevelDB → compendiums/YAML
pnpm packs:audit        # audit asset references in YAML (exit 1 on worlds/ refs)
pnpm packs:migrate-assets  # rewrite asset paths across YAML
pnpm build              # audit then build (what CI runs)
```

## Architecture

This is a **FoundryVTT v14 module** (`warbound-campaign-content`) for a Warbound campaign using the COF2 RPG system.

### Data flow

```
compendiums/*.yml  ←→  packs/  (LevelDB)
    ↑ source of truth      ↑ generated artifact — never edit directly
```

Pack types: `actors`, `adventures`, `items`, `journals`, `playlists`, `scenes` (plus `cards`, `macros`, `tables`).

YAML filenames follow: `{type}_{SafeName}_{_id}.yml` (generated by `pushLDBtoYAML.mjs`).

### Module structure

- `compendiums/` — YAML source. Edit here, then build.
- `packs/` — compiled LevelDB output. Git-ignored in CI; rebuilt on release.
- `scripts/warbound.mjs` — Foundry bootstrap: applies `warbound-theme` CSS class, injects logo in Settings sidebar, sets default actor image via `preCreateActor` hook.
- `styles/warbound.css` — full journal/UI theme (Horde dark editorial style).
- `assets/` — images, SVGs, fonts, UI elements. All referenced via `modules/warbound-campaign-content/` prefix.
- `tools/` — build scripts using `@foundryvtt/foundryvtt-cli`.
- `module.json` — Foundry manifest. Declares packs, styles, esmodules, hotReload paths.

### Asset path policy (enforced by audit)

| Prefix | Result |
|---|---|
| `worlds/...` | **BLOCKING ERROR** — not portable |
| `modules/warbound-campaign-content/...` | OK (checks file exists locally) |
| `systems/co2/...` | OK |
| `icons/` or `ui/` | OK (Foundry Core) |
| `http(s)://...` or `data:` | OK |
| Other module/system refs | WARNING only |

### Journal DA (design system)

CSS classes for journal HTML pages:
- `wb-page` — base wrapper (default: Horde; variants: `wb-neutral`, `wb-alliance`)
- `wb-readaloud`, `wb-box wb-gm`, `wb-box wb-lore`, `wb-box wb-clue`, `wb-box wb-danger`, `wb-box wb-rule`, `wb-box wb-npc`
- `wb-statblock`, `wb-columns`, `wb-hero`, `wb-portrait`, `wb-dropcap`, `wb-lead`, `wb-kicker`, `wb-tag`

See `examples/journal-components.html` for copy-paste blocks.

### Release

Releases built by GitHub Actions: audit → delete `packs/` → rebuild → zip → GitHub Release. The `packs/` directory in the repo is the last built state; it is regenerated on every release.
